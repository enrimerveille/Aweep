# Aweep

**Gardez votre Mac éveillé, quand vous en avez besoin.**

Aweep est une application native macOS qui permet de gérer l'éveil de votre Mac et de programmer sa mise en veille ou son extinction. Développée par Angry Thread.

**[Télécharger Aweep 1.0.2 (DMG)](https://github.com/enrimerveille/Aweep/releases/download/1.0.2/Aweep-1.0.2.dmg)** · [Toutes les versions](https://github.com/enrimerveille/Aweep/releases)

## Fonctionnalités

- **Système** — laisser macOS gérer la veille normalement.
- **Éveillé** — garder le Mac actif tout en permettant à l'écran de s'éteindre.
- **Temporaire** — rester éveillé pendant une durée choisie.
- **Transport** — maintenir l'activité sur les portables compatibles, avec des protections dédiées.
- **Programmation** — planifier une veille ou une extinction.

Interface en français et en anglais, accessible depuis la barre des menus ou une fenêtre dédiée.

## Compatibilité

**macOS 26 ou plus récent · Intel et Apple silicon.**

## Installation

Ouvrez le DMG et glissez Aweep dans **Applications**. L'application demande une autorisation macOS pour son service privilégié.

Aweep est signée **Apple Development, sans notarisation** : une autorisation manuelle dans les réglages de sécurité macOS peut être nécessaire.
